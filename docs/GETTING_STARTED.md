# 🚀 Getting Started (시작하기 가이드)

본 가이드는 **AIRIS (Lead Engineer) AI 에이전트 환경**을 새로운 개발 프로젝트나 신규 PC에 처음 세팅할 때 필요한 절차를 안내합니다.

---

## 📋 1. 사전 요구사항
작업을 시작하기 전 아래 도구들이 설치되어 있어야 합니다.
- **Git**: 리포지토리 동기화 및 관리용
- **Claude Code**: AI 에이전트 인터페이스 (필수)
- **PowerShell**: 윈도우 환경 스크립트 실행용 (관리자 권한 권장)

---

## 🛠️ 2. 초기 셋업 절차

새로운 프로젝트에 본 AI 에이전트의 뇌(지침 및 규칙)를 이식하려면 아래 순서대로 진행하세요.

### 1) AI 세팅 리포지토리 클론
먼저 AI 설정 파일들을 담아둘 폴더(예: 작업공간 최상위)에서 본 리포지토리를 클론합니다.
```powershell
# AI 설정 리포지토리 복제
git clone https://github.com/oyuobweo/AI_Settings.git
cd AI_Settings
```

### 2) AI 시스템 환경 동기화 (중요)
본 리포지토리 내부에 있는 셋업 스크립트를 실행하여, AI의 성능 설정(Token limit 등)과 글로벌 기술 표준 규약들을 셋업합니다.
```powershell
# backups 폴더 내의 셋업 스크립트 실행 (PowerShell)
.\backups\harmony-setup.ps1
```
*※ 이 스크립트는 AI 에이전트가 앞으로 작업을 수행할 때 반드시 지켜야 할 마스터 룰(`.claude/rules/`)을 시스템에 인지시킵니다.*

---

## 🔄 3. 일상적인 동기화 (협업/Multi-PC)

두 대 이상의 PC에서 교대로 작업하거나 지침이 업데이트되었을 때는 아래 루틴을 권장합니다.

1. **작업 시작 전**: `AI_Settings` 폴더에서 `git pull`을 통해 최신 AI 지침과 규칙을 가져옵니다.
2. **개발 진행**: AI 에이전트(AIRIS)가 업데이트된 `.claude/rules/`를 자동으로 읽어 기술 표준을 준수하며 코드를 작성합니다.
3. **지침 수정 시**: 룰을 변경했다면 `git add .`, `git commit`, `git push`를 통해 본 저장소에 반영합니다.

---

## 💡 꿀팁: AI와 대화하기
본 시스템은 **AIRIS v2.1** 규격에 의해 관리됩니다. AI에게 파일 생성이나 수정을 요청할 때 별도로 복잡한 프로젝트 규칙을 일일이 타이핑하지 않아도, AI는 이미 `.claude/rules/`를 통해 모든 표준을 완벽히 인지하고 있습니다.

- 코딩 리뷰 요청 예시: "현재 프로젝트의 기술 표준(ENGINEERING_STANDARDS.md)에 맞춰 이 코드를 리뷰해줘"
- 아키텍처 설계 요청 예시: "우리가 정의한 웹 패턴(WEB_BEST_PRACTICES.md)에 따라 컴포넌트를 분리해줘"
