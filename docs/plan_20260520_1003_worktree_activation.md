## 1) Problem Summary
- **현상**: 사용자가 Antigravity의 프로젝트 워크스페이스 생성창에서 `New Worktree` 옵션이 회색으로 비활성화되어 있는 구체적인 원인과 활성화 방법을 문의함.
- **해결책**:
  - `Worktrees are available for Git repositories` 경고의 의미를 명확히 해석하고, Git 저장소 초기화(`git init`)가 수행되지 않았음을 명쾌하게 규명한 뒤 즉각적인 조치 방법을 제공합니다.

---

## 2) Design Summary: 비활성화 원인 및 해결 로직
- **비활성화의 근본 원인**:
  - 대상 폴더가 일반 폴더이며 `.git` 메타데이터 디렉토리를 포함하고 있지 않음.
  - Git Worktree 기술은 Git의 오브젝트 데이터베이스(Ref, Commit)를 물리적으로 추적하고 연동해야 하므로, Git 버전 관리가 켜지지 않은 폴더에서는 시스템이 기능을 원천 차단함.
- **해결 방법**:
  - 1단계: 프로젝트 폴더 내부로 진입.
  - 2단계: 터미널에서 `git init` 명령어를 실행하여 로컬 Git 저장소로 강제 변환.
  - 3단계: 툴에서 재인식하면 즉각 `New Worktree` 기능 활성화 완료.

---

## 3) Implementation Plan
1. **[Direct Cause]** 비활성화 회색 문구의 정확한 아키텍처적 인과 관계를 알기 쉽게 해설.
2. **[Command Line Guide]** 사용자가 파워쉘이나 터미널에서 `git init` 명령 한 줄로 일반 폴더를 Git 저장소로 탈바꿈시켜 즉시 활성화하는 극도로 친절한 가이드 제공.

---

## 4) Verification Plan
- **수동 검증**: 가이드에 따라 `git init`을 수행하면 툴에서 Worktree 인터페이스가 정상 렌더링되는지 기술 명세 확인.
