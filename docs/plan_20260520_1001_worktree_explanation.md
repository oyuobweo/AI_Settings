# 태스크 계획서: Antigravity 워크스페이스 모드(Local vs Worktree) 아키텍처 해설
---
- **작성일시**: 2026년 5월 20일 10:01
- **버전**: v1.0
- **상태**: 승인 대기 (Draft)

---

## 1) Problem Summary
- **현상**: 사용자가 Antigravity(AI 코딩 툴)의 워크스페이스 선택 옵션창에 나타난 'Local' 모드와 'New Worktree' 모드의 핵심 차이점을 묻고 있음.
- **해결책**:
  - Git 아키텍처 관점에서 두 모드의 메커니즘을 규명하고, 사용자가 본인의 개발 상황(Cost-Revit 프로젝트 시작 등)에 맞춰 최적의 모드를 선택할 수 있도록 직관적인 비유와 특징을 제공합니다.

---

## 2) Design Summary: 두 모드의 정의 및 핵심 차이
- **Local (로컬)**:
  - 개념: 실제 현재 물리 디렉토리 파일을 AI와 직접 공유하여 실시간으로 편집하는 모드.
  - 장점: 즉각적이고 직관적임. 소스코드 변경을 바로바로 확인 가능.
  - 단점: AI가 광범위한 실험적 코드를 짤 때 메인 소스코드가 꼬일 우려가 있음.
- **New Worktree (새 워크트리)**:
  - 개념: `git worktree` 기술을 백그라운드에서 사용하여 물리적으로 분리된 별도 작업 공간(Worktree)을 생성해 병렬 개발하는 모드.
  - 장점: 메인 작업 브랜치를 전혀 건드리지 않고 AI에게 실험적이고 대형 태스크를 안전하게 시킬 수 있음.
  - 단점: Git 저장소(Repository)가 구성되어 있는 상태에서만 활성화 가능.

---

## 3) Implementation Plan
1. **[Visual Metaphor]** '하나의 책상(Local)' vs '옆방의 독립된 책상 복사본(Worktree)' 비유를 사용하여 비전공자나 초보자도 0.1초 만에 납득할 수 있게 기술 해설 구성.
2. **[Action Guide]** 현재 사용자가 추천한 `Cost-Revit` 새 프로젝트를 시작할 때 어떤 모드를 고르는 것이 가장 유리한지 시니어 리더로서 권장안 제시.
