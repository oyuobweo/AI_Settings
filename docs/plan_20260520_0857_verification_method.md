## 1) Problem Summary
- **현상**: 사용자가 새로운 개발 프로젝트를 생성하여 진행할 때, 오늘 세팅한 최적화 마스터 룰셋(`master.md`)이 실제 AI의 뇌에 정상적으로 로드되어 동작하고 있는지 자가 검증(Self-Verification)할 수 있는 명확한 방법론이 요구됨.
- **해결책**:
  - `master.md` 내에 각인시켜 둔 **'RESPONSE FORMAT RULE (CRITICAL)'**을 이용하여, AI에게 검증 신호를 보내 즉시 탑재 여부를 눈으로 확인하는 직관적이고 쉬운 가이드라인을 제공합니다.

---

## 2) Design Summary: 검증 메커니즘
- **트리거 단어**: `"글로벌 룰셋 작동하고 있어?"` 또는 `"마스터 룰 원본 코드블록으로 출력해줘"`
- **정상 응답 스펙**:
  1. AI가 일반적인 포맷이 아닌, 마크다운 기호가 그대로 살아있는 **`` ```markdown `` 코드 블록**을 출력해야 함.
  2. 코드 블록 첫 라인에 `# AI_Agent Master Rules (v2.1 Master Full)`이 명시되어 있어야 함.
  3. 역할(Role) 부분에 중복이 제거된 `AI_Agent`가 정확하게 표기되어 있어야 함.
  4. 절대 지침 부분에 사용자 컴퓨터의 `AI_Settings` 절대 경로가 올바르게 녹아 있어야 함.

---

## 3) Implementation Plan
1. **[Verification Guide]** 사용자가 실제 프로젝트를 가동하고 대화창에서 바로 수행해볼 수 있는 1초 검증 명령어 가이드 제공.
2. **[Success Pattern]** 성공했을 때 AI가 출력하게 될 샘플 응답(성공 패턴)을 시각적으로 예시 제공하여 자가 검증이 매우 편해지도록 도움.

---

## 4) Verification Plan
- **수동 검증**: 본 가이드라인의 방법론이 실제 새로운 프로젝트 세션에서 일관된 마크다운 코드블록 출력을 강제하는지 확인.
