# 🤖 초보자용: 완벽한 AI 코딩을 위한 마법의 규칙서 (ECC)

이 문서는 개발을 처음 배우거나 AI 도구에 익숙하지 않은 분들도 최고 품질의 코드를 짤 수 있게 도와주는 **"AI 코딩 규칙서(ECC)"**의 사용 설명서입니다.

---

## 1. ECC(Everything Claude Code)가 뭔가요?
AI(예: Claude)에게 "웹사이트 만들어줘"라고 그냥 말하면 자기 마음대로 코드를 짭니다. 때로는 옛날 방식을 쓰기도 하고 오류투성이 코드를 주기도 합니다.
ECC는 전 세계 똑똑한 개발자들이 모여 만든 **"AI가 코딩할 때 절대 실수하지 않게 만드는 지침서(잔소리 목록)"** 입니다.

이 규칙서를 내 프로젝트에 넣어두면, AI가 코드를 짤 때 마치 **10년 차 수석 개발자가 옆에서 감시하고 있는 것처럼** 완벽한 최신 트렌드의 코드를 짜게 됩니다!

---

## 2. 엄청 쉬운 적용 방법 (단순 복사 + 붙여넣기!)

예전처럼 복잡한 스크립트를 실행해서 수백 개의 파일을 다운로드 받을 필요가 없습니다! 딱 필요한 것만 골라서 쓰면 됩니다.

1. 내 컴퓨터의 개발 폴더(코딩하는 폴더) 안에 `.claude` 라는 새 폴더를 만듭니다. (점 하나로 시작해야 합니다)
2. 그 안에 `rules` 라는 폴더를 만듭니다. (최종 경로: `내프로젝트/.claude/rules/`)
3. 지금 보고 계시는 이 리포지토리의 `ECC_Library` 폴더에 들어가 봅니다.
   - `1_공통_핵심규칙/`
   - `2_웹프론트엔드/`
   - `3_파이썬/`
   - `4_백엔드/`
   - `5_기타_전체언어팩/` (C++, C#, Rust, Swift, PHP 등 세상의 모든 언어가 보관된 창고)
4. 본인이 **사용하는 언어 폴더에 들어가서 규칙 파일(.md)들을 복사**합니다.
5. 아까 만든 내 프로젝트의 `.claude/rules/` 폴더 안에 **붙여넣기** 하면 끝입니다!

---

## 3. 예시 시나리오

**Q: 저는 리액트(React)로 웹사이트를 만들 거예요!**
- A: `ECC_Library/1_공통_핵심규칙/` 안의 파일을 모두 복사해서 내 폴더에 넣습니다.
- A: `ECC_Library/2_웹프론트엔드/` 안의 파일을 모두 복사해서 내 폴더에 추가로 넣습니다.
- **결과**: 이제 AI가 구식 코드를 짜지 않고 완벽한 최신 리액트 코드로만 대답하게 됩니다!

**Q: 저는 파이썬(Python)으로 데이터 분석을 할 거예요!**
- A: `ECC_Library/1_공통_핵심규칙/` 과 `ECC_Library/3_파이썬/` 폴더 안의 파일만 복사해서 넣으면 됩니다!

> 정말 쉽죠? 이제 AI에게 안심하고 코딩을 맡겨 보세요!
