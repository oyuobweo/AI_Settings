# 🚀 AI_Agent 통합 룰셋 보관소

이 리포지토리는 개발 초보자부터 전문가까지 누구나 **최고 품질의 코드를 짤 수 있게 도와주는 "AI 코딩 규칙서(ECC)"와 자동 설정 스크립트**를 보관하는 통합 마스터 창고입니다. 
아래 가이드만 순서대로 따라 하시면, AI가 최고 수준의 완벽한 코드를 짜도록 만들 수 있습니다!

---

## 📖 1단계: 프로젝트에 규칙서 적용하기 (2가지 방법)

AI에게 "웹사이트 만들어줘"라고 그냥 말하면 오류가 많은 코드를 줍니다. 하지만 이 **"규칙서(잔소리 목록)"**를 프로젝트에 세팅해주면, AI가 일관성 있고 완벽하게 코딩하게 됩니다.

### 방법 A: AI_Agent에게 맡기기 (스크립트 실행 완료 시 100% 자동)
복잡하게 폴더를 만들고 복사하실 필요가 전혀 없습니다. 아래 **2단계의 스크립트**를 한 번만 실행해 두면, 앞으로는 개발을 시작할 때 AI에게 아무렇게나 편하게 말해도 됩니다.
> *"나 아이폰 앱(또는 파이썬 봇) 하나 만들어 줘!"*
-> AI는 0.1초 만에 `AI_Settings` 창고로 달려가 규칙서를 읽어온 뒤 완벽한 코드를 짜기 시작합니다. 힌트조차 주실 필요 없습니다!

### 방법 B: 내가 직접 수동으로 세팅하기 (AI_Agent가 세팅을 못 해주는 환경일 때)
1. 개발을 진행할 실제 내 프로젝트 폴더 안에 `.claude` 라는 이름의 폴더를 만듭니다. (점 하나로 시작)
2. 그 안에 `rules` 라는 폴더를 만듭니다. (최종 경로: `내프로젝트/.claude/rules/`)
3. 지금 보고 계시는 이 깃허브 창고의 **`ECC_Library`** 폴더에 들어갑니다.
   - `1_공통_핵심규칙/`
   - `2_웹프론트엔드/`
   - `3_파이썬/`
   - `4_백엔드/`
   - `5_기타_전체언어팩/` (C++, C#, Rust, Swift, PHP 등 세상의 모든 언어 보관)
4. 본인이 개발에 **사용할 언어 폴더에 들어가서 규칙 파일(.md)들을 전부 복사**합니다. (예: 리액트로 웹을 만든다면 1번과 2번 폴더 내용을 복사)
5. 아까 만든 내 프로젝트의 `.claude/rules/` 폴더 안에 **붙여넣기** 하면 끝입니다!

---

## 🛠️ 2단계: AI 마스터 지능 셋업 (더블클릭 단 1초 만에 완료!)

복잡하게 파워쉘을 열고 폴더를 이동하여 명령어를 입력하실 필요가 전혀 없습니다!

1️⃣ 리포지토리 루트에 들어있는 **`ai-setup.bat`** 파일을 다운로드받습니다.
2️⃣ 다운로드받은 **`ai-setup.bat`** 파일을 마우스로 **더블클릭**하여 실행합니다!
*(자동으로 파워쉘 우회 환경을 호출하여 GitHub 원격지로부터 최신 셋업 스크립트를 다운로드받아 클론 및 웜홀 셋업을 원스톱으로 완수합니다.)*
